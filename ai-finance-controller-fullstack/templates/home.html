What it does
⟷

Deterministic reconciliation

Exact match, then confidence-scored fuzzy match for rounding drift, settlement lag, and reference typos. Date-bucketed so it stays fast on large files, with a hard gate so a similar-looking reference id can never override a genuinely wrong amount.

◈

Settlement Q&A

Ask "what's the match rate?" or "why wasn't TXN123 matched?" and get an answer computed from the real data. An optional Anthropic API key can be configured on the server for open-ended questions — never pasted into the browser.

▲

Auditable forecasting

A plain linear trend over matched settlement volume, projected 7 days out. Simple enough to check by hand — a forecast nobody can audit isn't one finance teams can act on.

⇪

Bring your own data

Use sample data, upload your own bank + gateway CSVs, or fetch one from a URL — parsed and column-mapped server-side, so it works whether the file has 50 rows or 50,000, and a URL fetch is never blocked by browser CORS.
